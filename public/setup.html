내 기기 연결하기

기본 화면은 가입 없이 사용할 수 있습니다. 기기 동기화와 PC 알림은 아래 연결이 필요합니다.

차트 선택

기본 TradingView 차트에서 왼쪽 그리기 도구와 위쪽 지표·시간봉 메뉴를 사용할 수 있습니다. 종목은 NOX 검색창·관심종목에서 바꿉니다. 위젯에 그린 선과 지표 설정은 NOX에 저장·동기화되지 않습니다. 기존 선은 NOX 차트로 전환하면 사용할 수 있습니다.

1. 무료 동기화

  1. Supabase에서 무료 프로젝트를 만듭니다.
  2. 소스 저장소의 supabase/setup.sql을 SQL Editor에서 실행합니다.
  3. 프로젝트 Authentication의 Site URL / Redirect URL에 NOX 사이트 주소를 등록합니다.
  4. NOX의 설정 · 동기화에 프로젝트 URL과 공개용 publishable/anon 키를 입력합니다.
  5. 계정을 만들고 이메일 확인 후 로그인합니다. 휴대폰에서도 동일 프로젝트와 계정으로 로그인합니다.

무료 요금제에는 한도가 있습니다. NOX는 유료 전환을 자동으로 신청하지 않습니다. 관심종목·NOX 차트의 선·알림을 동기화하며, 로그인한 본인 계정만 읽도록 구성합니다. TradingView 위젯의 선은 제외됩니다.

2. PC 텔레그램 알림

  1. 공식 BotFather로 봇을 만들고 자신의 봇에 /start를 보냅니다.
  2. 저장소를 개인 PC에 내려받아 Node.js 22 이상, pnpm으로 의존성을 설치합니다.
  3. .env.example을 .env로 복사합니다. 동기화 계정과 봇 토큰·자신의 chat ID를 PC에서 입력합니다.
  4. start-alerts.cmd를 실행합니다. 앱의 알림 탭에서 PC 연결 상태를 확인합니다.
현재 지원 범위

PC 알림은 직접 연결된 코인의 체결가를 약 15초 간격으로 조회합니다. 이 사이에 발생했다 사라지는 돌파는 놓칠 수 있습니다. 전원이 꺼지거나 절전 상태이면 감시하지 못합니다. 국내/미국 주식·지수 외부 위젯 및 일별 환율은 자체 알림·드로잉 동기화를 지원하지 않습니다.

3. 공유하기

TradingView에서는 차트의 카메라(이미지 가져오기) 버튼으로 이미지를 저장한 뒤 공유하세요. NOX 차트에서는 캡처 버튼으로 NOX 선을 포함한 PNG를 저장하거나 복사하세요. 파일 공유를 지원하는 휴대폰에서는 공유 메뉴에서 카카오톡·텔레그램을 고를 수 있습니다. PC 알림 이미지는 감시 프로그램이 최근 100개 봉과 저장된 NOX 선을 별도로 그려 첨부합니다. 위젯의 선과 지표는 포함되지 않으며 이미지 시간봉은 알림 생성 시 정합니다.

자세한 내용과 데이터 제공처·검증 범위는 소스 저장소의 README를 확인하세요. .env와 개인 설정 백업은 공개 저장소에 업로드하지 마세요.
